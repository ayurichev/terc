# Terč — website

Public website for **Terč**, an offline iOS app for studying the Czech gun-permit
(*zbrojní průkaz*) exam. Served via GitHub Pages at
<https://ayurichev.github.io/terc/>.

| Page | URL |

Static HTML + a single stylesheet, no build step. Edit and push to `main` to publish.
